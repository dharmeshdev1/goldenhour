# Security policy

Please report vulnerabilities privately through
[GitHub's security advisories](https://github.com/dharmeshdev1/goldenhour/security/advisories/new)
for this repository, not in a public issue. You will get an answer within a few days.

If an address of yours appears on the trail and you believe it should not, open an issue with the
address and the transactions that explain it. Every verdict comes with its reason, so a correction
is a matter of evidence.

The threat model, and what Goldenhour does and does not claim, are in
[docs/security.md](docs/security.md). The Guard's own threat model is in [docs/guard.md](docs/guard.md).
